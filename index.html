01Task and assumptions任务与假设

This is one integrated programming task, rather than a set of separately numbered questions. Each input row has four comma-separated fields:

这是一道完整的编程任务，而不是若干道分开编号的小题。每一行输入都有四个用逗号分隔的字段：

area_code,month_code,year,temperature_change

The temperature change is measured in degrees Celsius relative to the 1951–1980 baseline. A positive value contributes one positive year. Its magnitude is not added to the result.

温度变化以摄氏度计，是相对于 1951–1980 年基准值的变化量。只要数值为正，就记为一个“正年份”；数值本身的大小不会被加进结果。

  • Use MRJob and Hadoop, with one MRStep, and support more than one reducer.
  • Use a combiner (or in-mapper combining), a special key for order inversion, and secondary sort.
  • Keep all intermediate counts exact. Do not round the rate at any stage.
  • The threshold is supplied at run time and satisfies 0 < τ < 1.
  • 使用 MRJob 和 Hadoop，只用一个 MRStep，并且支持多个 reducer。
  • 使用 combiner（或 in-mapper combining）、一个用于顺序反转（order inversion）的特殊键，以及二次排序（secondary sort）。
  • 所有中间计数都保持精确，任何阶段都不要对比例做四舍五入。
  • 阈值在运行时传入，满足 0 < τ < 1。

The reference implementation treats blank or unparseable temperatures, NaN, and positive or negative infinity as invalid. It also skips malformed rows and years outside 1961–2019. Zero is valid but is not positive.

参考实现把空白或无法解析的温度、NaN、正无穷和负无穷都视为无效；格式错误的行，以及 1961–2019 之外的年份，也会被跳过。0 是有效值，但不算正数。

Year uniqueness. Counting rows implements counting years only when each (area, month, year) has at most one record. The supplied full dataset was checked and has no repeated year key. The assignment does not define a rule for duplicate years or conflicting observations; this solution does not invent one.

年份唯一性只有当每个 (area, month, year) 至多对应一条记录时，“数行数”才等于“数年份”。我们检查过所提供的完整数据集，其中没有重复的年份键。作业没有规定重复年份或相互冲突的观测该怎么处理，本解答也不会自行发明规则。

Area and month codes are parsed as integers and emitted in canonical decimal form. The assignment does not supply an extra whitelist of allowed area or month codes.

area 和 month 代码按整数解析，并以标准的十进制形式输出。作业没有另外提供允许使用的 area 或 month 代码白名单。

02Counts, periods and the threshold计数、时间段与阈值

For a fixed combination G = (month, area, period), let N be the number of years with a valid temperature change, and let P be the number of those years with temperature change > 0.

对一个固定的组合 G = (month, area, period)，令 N 为温度变化有效的年份数，P 为其中温度变化 > 0 的年份数。

R=PN,N>0

Emit the combination exactly when R ≥ τ. Equality is included. If N = 0, the rate is undefined and the combination is omitted.

当且仅当 R ≥ τ 时输出该组合，等号也算在内。若 N = 0，比例没有定义，该组合不输出。

After checking the year range, compute the period as follows:

先检查年份是否在范围内，再按下面的方式计算所属时间段：

start = 1961 + ((year - 1961) // 10) * 10
end = min(start + 9, 2019)

For 1970, the offset is 9, so integer division gives 0 and the start is 1961. For 1971, the offset is 10, so the start is 1971. Years 2011 and 2019 both map to start 2011, and the end is capped at 2019.

1970 年的偏移量是 9，整除 10 得 0，所以起点是 1961。1971 年的偏移量是 10，所以起点是 1971。2011 年和 2019 年都映射到起点 2011，终点被截到 2019。

The denominator is the observed valid-year count, not 10 or 9. As a supplementary teaching example, if only 2011 (+0.3) and 2019 (0) are valid in the last period, then P = 1, N = 2 and R = 0.5. It is output at τ = 0.5.

分母是实际观测到的有效年份数，而不是 10 或 9。举一个补充的教学例子：如果最后一个时间段里只有 2011（+0.3）和 2019（0）是有效的，那么 P = 1，N = 2，R = 0.5，在 τ = 0.5 时会被输出。

04The one-step MapReduce design一步完成的 MapReduce 设计

Mapper: two tagged keys per valid rowMapper：每条有效行发出两个带标签的键

Use the internal text key month|area|start|tag. The first three fields identify the combination. Tag 0 is the special denominator key; tag 1 is the numerator key.

中间键使用文本 month|area|start|tag。前三个字段确定是哪个组合；tag 0 是特殊的分母键，tag 1 是分子键。

month|area|start|0    1
month|area|start|1    int(temperature_change > 0)

For the negative sample row 2,7001,1962,-0.1, emit 7001|2|1961|0 with value 1 and 7001|2|1961|1 with value 0. An invalid temperature emits nothing. Even when the numerator is zero, the tag-1 key remains present for every combination containing a valid row.

以负值样例行 2,7001,1962,-0.1 为例：发出 7001|2|1961|0，值为 1；再发出 7001|2|1961|1，值为 0。无效温度不发出任何记录。即使分子为 0，只要组合里有一条有效行，tag 1 的键就一定存在。

Combiner: add integers, retain the full keyCombiner：只做整数相加，保留完整的键

For each full key, sum its integer values and emit that same key with the sum. Both mapper outputs and combined outputs use text-encoded integers, so they can be combined again.

对每个完整的键，把它的整数值加起来，再用同一个键发出这个和。mapper 的输出和 combiner 的输出都是文本形式的整数，所以可以被再次合并。

Do not average local rates. In a supplementary example, mapper A has (P, N) = (1, 1), and mapper B has (0, 3). Averaging rates gives (1 + 0) / 2 = 0.5, while adding counts gives (1 + 0) / (1 + 3) = 0.25.

不要对局部比例求平均。补充例子：mapper A 得到 (P, N) = (1, 1)，mapper B 得到 (0, 3)。对比例求平均得 (1 + 0) / 2 = 0.5，而把计数相加得 (1 + 0) / (1 + 3) = 0.25。

The partitioner passed to Hadoop Streaming uses the old mapred API: org.apache.hadoop.mapred.lib.KeyFieldBasedPartitioner. The comparator is org.apache.hadoop.mapreduce.lib.partition.KeyFieldBasedComparator. Set the key’s internal field separator to |, and use:

传给 Hadoop Streaming 的分区器使用旧版 mapred API：org.apache.hadoop.mapred.lib.KeyFieldBasedPartitioner。比较器是 org.apache.hadoop.mapreduce.lib.partition.KeyFieldBasedComparator。把键内部的字段分隔符设为 |，并使用：

-k1,1n -k2,2n -k3,3n -k4,4n

The n suffix requests numeric comparison. Area codes 2, 10 and 100 therefore appear in that order, rather than in the string order 10, 100, 2. Periods are ordered by their integer start years.

后缀 n 表示按数值比较。所以 area 代码 2、10、100 会按这个顺序出现，而不是按字符串顺序排成 10、100、2。时间段按整数起始年份排序。

Order inversion: the special tag-0 key supplies the denominator before the tag-1 calculation. Secondary sort: month is the partitioning field, while the remaining fields further order the input received by that reducer. This design does not need SORT_VALUES=True or a grouping comparator that collapses the key to the month.

顺序反转：特殊的 tag-0 键在 tag-1 计算之前先把分母送到。二次排序：month 是分区字段，其余字段对同一个 reducer 收到的输入做进一步排序。这个设计不需要 SORT_VALUES=True，也不需要一个只按月份分组的分组比较器。

Reducer: store a denominator, then emit a rateReducer：先存下分母，再输出比例

On tag 0, sum all denominator contributions and save the combination identity and denominator. On the immediately following tag-1 call, sum the numerator, check that the saved identity matches, compute the rate, and emit it if it meets the threshold. The next tag-0 call replaces the old state.

遇到 tag 0：把所有分母贡献加起来，保存组合标识和分母。紧接着的 tag-1 调用：把分子加起来，确认保存的组合标识一致，计算比例，达到阈值就输出。下一次 tag-0 调用会替换掉旧状态。

Tag position matters. The alternative month|tag|area|start would place multiple areas’ denominators before their numerators. Saving one denominator would then overwrite state needed by an earlier area. Put the complete combination identity before the tag so each pair remains adjacent.

tag 放在哪里很关键如果改成 month|tag|area|start，多个 area 的分母会全部排在它们的分子前面。reducer 只保存一个分母，就会把前面某个 area 还要用的状态覆盖掉。把完整的组合标识放在 tag 前面，每一对键才会紧挨在一起。

Default hashing of the full tagged key is also unsafe: G|0 and G|1 can be assigned to different reducers. Fixing the number of reducers to one would only mask this fault and would not meet the assignment’s multi-reducer requirement.

对带 tag 的完整键做默认哈希同样不安全：G|0 和 G|1 可能被分到不同的 reducer。把 reducer 数量固定为 1 只会掩盖这个错误，而且不满足作业对多个 reducer 的要求。

05Why the solution is correct为什么这个解答是正确的

1. The two sums equal the required counts1. 两个和正好等于所需的计数

Each valid year emits exactly one denominator contribution of 1. It emits a numerator contribution of 1 exactly when the temperature change is positive, and 0 otherwise. Invalid years emit neither. Under the stated uniqueness assumption, the tag-0 sum is therefore exactly N, and the tag-1 sum exactly P.

每个有效年份恰好发出一个值为 1 的分母贡献；当且仅当温度变化为正时，发出值为 1 的分子贡献，否则发出 0。无效年份两者都不发出。因此，在前面说明的唯一性假设下，tag-0 的和恰好是 N，tag-1 的和恰好是 P。

2. Any combiner schedule preserves those sums2. combiner 无论怎样执行，这两个和都不变

For a complete key, let its emitted values be x₁, …, xₙ. A combiner replaces any subset by its sum. Adding all remaining values in the reducer still yields x₁ + … + xₙ, by associativity and commutativity of integer addition. This holds with zero, one, or repeated combiner invocations. The reducer performs the final sum across mapper partitions.

对一个完整的键，设它发出的值为 x₁, …, xₙ。combiner 会把其中任意一部分替换成它们的和。reducer 再把剩下的值全部相加，结果仍然是 x₁ + … + xₙ——这由整数加法的结合律和交换律保证。不论 combiner 执行零次、一次还是多次，这一点都成立。跨 mapper 分区的最终求和由 reducer 完成。

3. A numerator always sees its own denominator3. 分子一定能拿到自己的分母

For a combination G, the two keys share the month and therefore reach the same reducer. Numeric lexicographic sorting puts G|0 directly before G|1: their first three fields agree, and 0 precedes 1. Keys for a different combination cannot appear between them. After the G|0 call, the saved state is precisely G and its full denominator. The next G|1 call therefore divides its numerator by the correct positive denominator.

对组合 G，它的两个键月份相同，所以会到达同一个 reducer。按数值的字典序排序会把 G|0 直接放在 G|1 前面：它们前三个字段相同，而 0 排在 1 前面。其他组合的键不可能插到它们中间。G|0 调用结束后，保存的状态正好是 G 和它完整的分母，所以接下来的 G|1 调用会用正确的正分母去除分子。

If there are no valid years, no key is emitted for that combination, so no undefined division is attempted. If the numerator is zero, the rate is zero and is excluded because τ > 0.

如果一个有效年份都没有，这个组合不会发出任何键，所以不会出现无定义的除法。如果分子为 0，比例就是 0，由于 τ > 0，它会被排除。

4. Filtering preserves the required order4. 筛选不会打乱要求的顺序

Groups arrive in numeric (month, area, start) order within a reducer. At most one result is emitted per group, at its tag-1 call. Threshold filtering removes some groups without exchanging any remaining groups, so output retains that order. Changing the final output key to the month does not invoke another sort; the result is already ordered at the point of emission.

在一个 reducer 内，各组按数值 (month, area, start) 的顺序到达。每组最多只在它的 tag-1 调用时输出一条结果。阈值筛选只会删掉某些组，不会交换剩下各组的位置，所以输出保持这个顺序。把最终输出的 key 换成月份，并不会触发新的排序；结果在输出的那一刻就已经有序。

The emitted set is exactly the combinations with a defined rate R ≥ τ, in the required order within every reducer.

输出的集合恰好是比例有定义且 R ≥ τ 的全部组合，并且在每个 reducer 内都符合要求的顺序。

"""Teaching reference: one MRStep, tagged keys, numeric secondary sort."""
import csv
import math

from mrjob.job import MRJob
from mrjob.step import MRStep
from mrjob.compat import jobconf_from_env
from mrjob.protocol import RawProtocol, JSONProtocol


class proj1(MRJob):
    INTERNAL_PROTOCOL = RawProtocol
    OUTPUT_PROTOCOL = JSONProtocol
    # Hadoop Streaming's -partitioner uses the old mapred API.
    PARTITIONER = 'org.apache.hadoop.mapred.lib.KeyFieldBasedPartitioner'
    JOBCONF = {
        'mapreduce.map.output.key.field.separator': '|',
        'mapreduce.partition.keypartitioner.options': '-k1,1',
        'mapreduce.job.output.key.comparator.class':
            'org.apache.hadoop.mapreduce.lib.partition.KeyFieldBasedComparator',
        'mapreduce.partition.keycomparator.options':
            '-k1,1n -k2,2n -k3,3n -k4,4n',
    }

    def mapper(self, _, line):
        try:
            fields = next(csv.reader([line]))
            if len(fields) != 4:
                self.increment_counter('input', 'invalid_record', 1)
                return
            area, month, year = (int(x.strip()) for x in fields[:3])
            temperature = float(fields[3].strip())
        except (ValueError, csv.Error):
            self.increment_counter('input', 'invalid_record', 1)
            return
        if not math.isfinite(temperature) or not 1961 <= year <= 2019:
            self.increment_counter('input', 'invalid_or_out_of_range', 1)
            return
        start = 1961 + ((year - 1961) // 10) * 10
        base = f'{month}|{area}|{start}'
        # Tag 0 is the special denominator key; tag 1 is the numerator key.
        yield base + '|0', '1'
        yield base + '|1', str(int(temperature > 0))

    def combiner(self, key, values):
        yield key, str(sum(int(value) for value in values))

    def reducer_init(self):
        raw_tau = jobconf_from_env('myjob.settings.tau')
        if raw_tau is None:
            raise ValueError('Set --jobconf myjob.settings.tau=<value>')
        self.tau = float(raw_tau)
        if not math.isfinite(self.tau) or not 0 < self.tau < 1:
            raise ValueError('tau must satisfy 0 < tau < 1')
        self.current_group = None
        self.denominator = 0

    def reducer(self, key, values):
        month, area, start, tag = (int(x) for x in key.split('|'))
        group = (month, area, start)
        count = sum(int(value) for value in values)
        if tag == 0:
            self.current_group = group
            self.denominator = count
        elif tag == 1:
            if group != self.current_group or self.denominator <= 0:
                raise ValueError('Missing denominator: check partition/sort settings')
            rate = count / self.denominator
            if rate >= self.tau:
                end = min(start + 9, 2019)
                yield str(month), f'{area},{start}-{end},{rate}'
        else:
            raise ValueError('Unknown key tag')

    def steps(self):
        return [MRStep(mapper=self.mapper,
                       combiner=self.combiner,
                       reducer_init=self.reducer_init,
                       reducer=self.reducer)]


if __name__ == '__main__':
    proj1.run()

reducer_init initializes task state once. Do not reset current_group and denominator at the start of every reducer call. The use of a generator inside sum consumes values incrementally rather than storing them in a list.

08Complexity and partitioning trade-off复杂度与分区的取舍

Let L be the number of input rows and V the number of valid in-range rows. The mapper scans all rows in O(L) time and emits exactly 2V records before optional combining. Combiner and reducer accumulation each perform constant work per received count, under the standard unit-cost model for these small identifiers and counters.

设 L 为输入行数，V 为范围内的有效行数。mapper 用 O(L) 时间扫描所有行，在可选的合并之前恰好发出 2V 条记录。对于这些较小的标识和计数器，按标准的单位代价模型，combiner 和 reducer 对收到的每个计数都只做常数量的工作。

The Python reducer keeps a threshold, one group identity and one denominator: O(1) scalar state. It does not retain all records or all output groups. An integer counter’s bit length grows logarithmically with the number of observations; the scalar-state claim is not a claim of literally fixed bits for arbitrary-sized inputs.

Python reducer 只保存一个阈值、一个组合标识和一个分母：O(1) 个标量状态。它不会保留全部记录，也不会保留全部输出组。整数计数器的位数会随观测数量对数增长；“标量状态为常数”并不是说输入无论多大，占用的比特数都严格固定。

Hadoop performs shuffle and external sorting. Their storage, network, and sorting costs are separate from the reducer’s additional Python memory. A combiner can reduce communication but is not required for correctness.

shuffle 和外部排序由 Hadoop 完成。它们的存储、网络和排序开销，与 reducer 额外占用的 Python 内存是分开计算的。combiner 可以减少通信量，但不是正确性所必需的。

Month-only partitioning makes co-location and ordering easy to explain. It limits effective parallelism to the number of distinct valid months, typically at most 12 in this dataset, and can create a hot reducer for a large month. This solution satisfies the assignment’s multi-reducer requirement without claiming optimal load balancing.

只按月份分区，让“相关键放在一起”和“排好顺序”都很容易解释。但它把有效并行度限制在不同有效月份的数量上——在这个数据集里通常最多 12 个；数据量大的月份还可能让某个 reducer 负载过重。这个解答满足作业的多 reducer 要求，但并不宣称负载均衡是最优的。
